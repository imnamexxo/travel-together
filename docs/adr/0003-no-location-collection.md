# 사람의 위치 좌표를 수집하지 않는다

GPS 이동경로 기록을 없애고, 지도는 장소 핀(들른 곳과 계획만 한 곳)만 보여준다. 앱은 기기 위치 권한을 요청하지 않고, 서버 API는 어떤 경우에도 사람의 위치 좌표를 받거나 저장하지 않는다. 사진의 촬영 GPS는 휴대폰 안에서 가까운 장소를 찾는 데만 쓰고 버리며, 업로드하는 사진 파일에서도 EXIF를 지운다. 백그라운드 위치 기록은 위치정보법상 개인위치정보 수집(위치기반서비스사업 신고 대상 가능성)과 스토어의 백그라운드 위치 권한 심사를 부르는데, 실제 이동 궤적은 이 앱의 핵심 가치가 아니어서 그 부담을 지지 않기로 했다. "경로 기록을 다시 넣자"는 제안은 이 두 부담을 감수할지부터 다시 따져야 한다.

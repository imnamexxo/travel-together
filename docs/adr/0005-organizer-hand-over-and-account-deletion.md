# 총무는 넘길 수 있고, 탈퇴해도 남의 정산은 깨지지 않는다

총무는 처음에는 여행을 만든 멤버이고, 총무가 다른 멤버에게 넘길 수 있다. 회원 탈퇴는 앱 안에서 바로 처리한다. 스토어 등록 조건이고, 정식 출시가 목표이기 때문이다. 탈퇴하면 Supabase 로그인 계정을 지우고 여행 데이터는 다음 규칙대로 처리한다. 내가 총무인 여행에 다른 멤버가 있으면 가장 먼저 들어온 멤버에게 총무가 넘어간다. 나 혼자인 여행은 통째로 지운다. 내가 올린 사진은 모든 여행에서 지운다. 지출·송금에 엮인 멤버 기록은 남기고 이름만 "탈퇴한 멤버"로 바꾼다. 엮이지 않았으면 여행에서 뺀다. 프로필은 탈퇴 시각과 함께 남는다. 남은 지출 기록이 이 프로필을 가리키고, 아직 만료되지 않은 로그인 토큰으로 프로필을 되살리거나 여행에 접근하는 것을 막는 표식이기 때문이다. 탈퇴 확인 화면은 서버가 계산한 미리보기(삭제될 여행, 총무가 넘어갈 여행, 기록이 남는 여행)를 그대로 보여 준다.

지출 기록까지 지우는 방법은 남은 멤버의 잔액과 송금 제안을 바꿔 버려서 택하지 않았다. 지출에 엮였으면 탈퇴를 막는 방법(지금의 "나가기" 규칙)은 정산이 끝난 여행 때문에 영영 탈퇴하지 못하는 경우가 생겨 택하지 않았다. 탈퇴할 때 총무를 받을 사람을 고르게 하는 대신 가입 순서로 자동으로 정했다. 다른 사람을 원하면 탈퇴 전에 여행 설정에서 직접 넘기면 된다. 로그인 계정 삭제가 실패하면 DB 변경도 되돌린다. 계정은 남았는데 데이터만 지워진 상태를 만들지 않기 위해서다.

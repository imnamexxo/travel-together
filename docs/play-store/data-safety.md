# Play Console 데이터 보안 양식 답안

Play Console → 앱 → **정책 및 프로그램 → 앱 콘텐츠 → 데이터 보안**에 입력할 답이다. 2026-11-27 코드 기준이다(Sentry 오류 수집 추가). 앱이 보내는 데이터가 바뀌면 이 표와 [개인정보 처리방침](https://kang1031-frontend.expo.app/privacy)(`frontend/public/privacy.html`)을 함께 고친다.

## 판단 기준 (Play 정의)
- **수집**: 앱 밖(우리 서버나 외부 업체)으로 보내는 것. 기기 안에서만 쓰고 버리면 수집이 아니다.
- **공유**: 제3자에게 넘기는 것. 우리 대신 처리하는 서비스 제공업체(Supabase, Render, Google Gemini/Places, 카카오 검색, Sentry)에 보내는 것은 공유가 아니다. 사용자가 직접 여행 멤버에게 보여 주는 것도 공유가 아니다.
- **일시적으로 처리**: 요청을 처리할 때만 메모리에서 쓰고 저장하지 않는 것.

## 1단계: 데이터 수집 및 보안
| 질문 | 답 |
|---|---|
| 앱에서 필수 사용자 데이터 유형을 수집하거나 공유하나요? | **예** |
| 수집된 모든 사용자 데이터가 전송 중에 암호화되나요? | **예** (모두 HTTPS) |
| 사용자가 데이터 삭제를 요청할 수 있는 방법을 제공하나요? | **예** |
| 계정 생성 방법 | **사용자 이름과 비밀번호**(이메일 가입), **OAuth**(카카오, Google) |
| 계정 삭제 URL | https://kang1031-frontend.expo.app/delete-account |

## 2단계: 데이터 유형 (체크할 것)
| 범주 → 유형 | 수집 | 공유 | 일시적 처리 | 필수/선택 | 목적 | 근거 |
|---|---|---|---|---|---|---|
| 개인 정보 → **이름** | 예 | 아니요 | 아니요 | 필수 | 앱 기능, 계정 관리 | 표시 이름(멤버에게 보임) |
| 개인 정보 → **이메일 주소** | 예 | 아니요 | 아니요 | 필수 | 계정 관리 | 로그인 계정 |
| 개인 정보 → **사용자 ID** | 예 | 아니요 | 아니요 | 필수 | 앱 기능, 계정 관리 | 로그인 계정 id, 카카오·Google 계정 식별자 |
| 금융 정보 → **기타 금융 정보** | 예 | 아니요 | 아니요 | 선택 | 앱 기능 | 지출(상호, 금액, 결제자), 송금 기록. 결제 수단 정보는 받지 않음 |
| 사진 및 동영상 → **사진** | 예 | 아니요 | 아니요 | 선택 | 앱 기능 | 앨범 사진, 영수증 사진(Gemini 분석 포함) |
| 앱 활동 → **기타 사용자 제작 콘텐츠** | 예 | 아니요 | 아니요 | 선택 | 앱 기능 | 여행 이름, 일정, 메모, 친구 관계 |
| 앱 활동 → **인앱 검색 기록** | 예 | 아니요 | **예** | 선택 | 앱 기능 | 장소 검색어. 서버를 거쳐 카카오·Google에 보내고 저장하지 않음 |
| 앱 정보 및 성능 → **비정상 종료 로그** | 예 | 아니요 | 아니요 | 필수 | 분석 | 앱 오류 기록(Sentry). 오류 내용, 화면 이동, 요청 경로(검색어 제거). 이메일·IP 없음, 콘솔 로그 없음 |
| 앱 정보 및 성능 → **진단** | 예 | 아니요 | 아니요 | 필수 | 분석 | 오류 때의 기기 모델, OS·앱 버전, 메모리 상태(Sentry) |
| 앱 정보 및 성능 → **기타 앱 성능 데이터** | 예 | 아니요 | 아니요 | 필수 | 분석 | 서버 로그(요청 경로 모양, 처리 시간). 사용자 id·IP 없음 |

## 체크하지 않는 것
| 범주 | 이유 |
|---|---|
| 위치(대략적·정확한) | 위치 권한을 요청하지 않고, 사진의 촬영 위치도 읽지 않는다. 사진에 연결되는 장소는 사용자가 목록·검색에서 직접 고른 가게·관광지다(ADR-0003, 위치정보지원센터 답변 2026-11-26). |
| 개인 정보 → 주소, 전화번호 등 | 받지 않는다 |
| 금융 정보 → 결제 정보, 구매 기록, 신용 점수 | 앱 안 결제가 없다 |
| 연락처, 캘린더, 메시지, 오디오, 파일 및 문서, 건강 | 기기의 이런 데이터에 접근하지 않는다 |
| 웹 브라우징, 설치된 앱, 앱 상호작용 | 수집하지 않는다(광고·분석 SDK 없음. Sentry의 화면 이동 기록은 오류 보고에만 붙는 진단 정보로 본다) |
| 기기 또는 기타 ID | 광고 ID나 기기 ID를 쓰지 않는다 |

## 판단이 갈릴 수 있는 것
- **비정상 종료 로그·진단 필수 여부**: 앱 안에서 끌 수 없으므로 필수로 답한다.
- **기타 앱 성능 데이터**: 서버 로그는 사용자와 연결되지 않아서 빼도 된다는 해석도 있다. 숨겼다는 지적을 피하려고 넣었다.
